# Image to PDF Converter

A simple web application that converts multiple images into a single PDF file.

## Live Demo

https://image-to-pdf-converter-dofx.onrender.com

## Features
- Upload multiple images
- Preview selected images
- Convert images to PDF
- A4 PDF format
- Supports JPG, PNG and WEBP
- Mobile-friendly interface

## Technologies
- Python
- Flask
- Pillow
- ReportLab
- HTML, CSS, JavaScript
- Git & GitHub
- Render

## How It Works
1. Select multiple images.
2. JavaScript shows image previews.
3. Flask receives the images.
4. Pillow processes the images.
5. ReportLab creates the PDF.
6. The PDF is returned for download.

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000 in your browser.
